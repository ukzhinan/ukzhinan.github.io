<h2 id="sec-1">先检查自己能否登录与查看身份</h2>

eVisa 是移民身份与许可条件的电子记录，通过 UKVI 账户访问；建立账户和查看 eVisa 不收费。先从[GOV.UK eVisa 官方入口](https://www.gov.uk/evisa)进入，不通过广告中的代办登录页。

按系统要求使用登记的证件或账户资料登录，确认接收验证码的手机或邮箱仍由自己控制。查看姓名、出生日期、身份类别和有效期；如果显示错误，保存错误说明并走[官方报错入口](https://www.gov.uk/evisa/report-error-evisa)，不要把技术错误自行理解为已经失去或获得某项权利。

**本页办理入口核对于 2026-09-19。** 账户操作不等于申请或延长签证；个人资格和期限问题联系学校授权的签证顾问。

<h2 id="sec-2">按用途生成和交付 share code</h2>

| 办事场景 | 怎么准备 | 还需核对什么 |
| --- | --- | --- |
| 雇主核对工作权限 | 使用证明工作权的服务入口，提供对应 share code 与出生日期 | 工作条件与课程期间限制，见[打工政策]({{ '/gongzuo/dagong-zhengce/' | relative_url }}) |
| 英格兰租房身份核查 | 按 right to rent 入口生成代码 | 并非全英国统一的租房核验制度 |
| 学校或其他机构核验 | 问清对方用途，按官方系统相应选项操作 | 是否另需录取或学生身份证明 |
| 航空公司要求补充证明 | 旅行前按官方说明准备 share code | 护照关联、个人信息与客票资料一致 |

GOV.UK 说明 share code 有效期为 **90 天**，到期可重新生成；代码不是签证延期，也不改变许可条件。详情与入口见[查看 eVisa 和生成 share code](https://www.gov.uk/evisa/view-evisa-get-share-code-prove-immigration-status)、[证明工作权](https://www.gov.uk/prove-right-to-work)及[证明租房权](https://www.gov.uk/prove-right-to-rent)。

把对应代码交给确实需要核验的机构。不要交出 UKVI 登录密码、邮箱密码或验证码，也不要把含个人资料的页面发进公开群。

<h2 id="sec-3">换护照、换手机号或搬家后更新</h2>

更新前先确保旧登录方式仍能使用；换手机或停用号码前，安排好新的验证方式。需要更新的资料包括护照、姓名、手机、邮箱及地址等。

从[UKVI 更新资料入口](https://www.gov.uk/evisa/update-ukvi-account)办理，保存提交记录，并再次登录检查结果。**等待签证决定期间，官方更新服务对姓名及护照变更有限制**，应先读该页面并向 UKVI 或学校签证团队询问处理方式。

已有资料改变与原本显示错误有不同入口；不要反复新建账户来尝试覆盖旧记录。

<h2 id="sec-4">旅行前与柜台受阻时</h2>

出行前核对三处：旅行使用的有效护照已加入 UKVI 账户；eVisa 显示正确；航空公司旅客资料与护照及账户一致。护照在境外换发时，按官方说明确认能否自行更新以及后续手续。

如果航空公司无法核验 eVisa，可请工作人员联系 **UK Border Force carrier support hub**。官方说明及补充证明方式见[使用 eVisa 旅行](https://www.gov.uk/evisa/travel-with-evisa)。准备好行程、有效护照和官方要求的证明，预留处理时间；截图和签证决定信不能保证代替实际核验。

英国身份也不代替目的地或转机国家的入境许可，旅行资格另查[出行规划]({{ '/lvxing/guihua/' | relative_url }})。

<h2 id="sec-5">问题分类与求助记录</h2>

| 问题 | 下一步 |
| --- | --- |
| 无法收验证码、旧邮箱失效 | 使用官方更新页面中的账户恢复帮助 |
| 能登录但身份显示错误或无法生成代码 | 使用官方 eVisa 报错服务 |
| 不清楚自己能否工作、租房或申请下一种签证 | 联系学校签证团队，必要时咨询受监管移民顾问 |
| 护照丢失 | 同时处理证件补办与账户更新，见[护照丢失步骤]({{ '/anquan/tufa-qingkuang/#sec-5' | relative_url }}) |

> I can [sign in / view my eVisa], but [describe the error]. I first noticed this on [date]. My next [travel / employment / enrolment] date is [date]. Please advise which service I should use and how to track the report.

只通过官方安全渠道提交证件；普通求助邮件先描述问题，不附完整证件扫描件。记下报错时间、案件编号和约定的跟进方式。
