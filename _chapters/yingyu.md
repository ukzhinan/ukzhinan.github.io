faq:
  - q: "course 和 module 到底哪个是「一门课」？"
    a: "**在英式用法里 course 指整个学位课程，module 才是一门课。**「I'm doing a course in History」意思是在读历史这个学位，而不是修了一门历史课；一门课要说 module，如「I've got three modules this term」。这跟美式用法正好错位，照美式理解容易在跟教务处沟通选课、退课时说反。口语里说 class 一般指某一次上课，不是整门课。"
  - q: "可以直接叫老师的名字吗，还是要叫 Professor？"
    a: "**看对方邮件签名怎么署名，这是最可靠的判断依据。**签「Best, Sarah」就可以回 Dear Sarah；签「Dr S. Smith」就写 Dear Dr Smith。另外英国的 professor 只指正教授（相当于讲席/正教授职称），把普通讲师叫 Professor 并不礼貌加分，反而显得不了解情况——有博士学位的一律 Dr 最安全。不确定时用 Dear Dr Smith，几乎不会出错。"
  - q: "写给学校的邮件，多正式才合适？"
    a: "**比跟朋友说话正式一层，但不必写成公文。**实际标准是：有称呼（Dear + 姓名）、开头一句说清你是谁和什么事（附学号与模块代码）、中间分点、结尾 Kind regards 加全名。要避免的是两个极端——「Hi mate, can I skip the class?」会被读成不知分寸，而刻意堆砌 herewith、kindly be advised 之类的词只会让人读得费劲。本表的「正式」列给的就是这一层的用词。"
  - q: "这张表里的词，哪些是英式和美式差别最容易踩坑的？"
    a: "最常误事的几组：**module / course**（一门课 vs 整个学位）、**dissertation / thesis**（英国本硕叫 dissertation、博士叫 thesis）、**chemist / pharmacy**（chemist 是药店，不是化学家）、**enrol / enroll**（英式单 l）、**flat / apartment**、**takeaway / takeout**、**A&E / ER**（英国急诊叫 A&E）。表里这几条都单独标了区别。"

这一页把留学中最常撞上的中英文说法排成对照表，共 178 条，按场景分五类。**口语列**是同学、室友、朋友之间怎么说；**正式列**是写邮件、交作业、填表格、跟学校行政或房东打交道时该怎么写。

两列不是对错关系，是场合关系。跟朋友说「I've got a lecture at nine」很自然，给教务处写邮件就该是「I have a lecture scheduled at 9:00」。用之前有三点值得先知道：

- **搞混场合比用错词更容易出问题。**给讲师的邮件里写「Hi mate, can I skip the class?」，对方不会觉得亲切，只会觉得你不知道分寸；反过来跟室友说「I shall commence my laundry」也一样奇怪。
- **英式用词和美式常有一层错位。**module 不是 course、dissertation 不是 thesis、chemist 不是化学家——这类词照美式理解会直接误事，表里都单独标了。
- **称呼老师就按对方的邮件签名来。**英国 professor 只指正教授，其他一律 Dr 或 lecturer；对方签「Best, Sarah」就可以叫 Sarah，签「Dr S. Smith」就写 Dr Smith。

> 有几个词（急诊、心理咨询、室友、校园安保等）在两个分类里各出现一次——因为按场景查表时，你未必记得它被归到了哪一类。

<h2 id="sec-1">学校与学习</h2>

| 中文 | 口语（同学之间） | 正式（邮件、作业、文件） | 说明 |
| --- | --- | --- | --- |
| **学校** | uni | university | 在非正式场合，学生常称大学为“uni”。在正式文件或专业交流中，使用“university”。 |
| **学院/系** | dept | department | 大学内部的学科单位，如工程学院（Department of Engineering）或历史系（Department of History）。 |
| **专业** | subject/major | programme/discipline | 口语中常说“major in”（如“我主修生物”）。在正式文件中，使用“programme of study”或“discipline”指学习领域。 |
| **学期** | term | academic term | 英国通常有 Autumn, Spring, Summer 三个学期，每个学期涵盖特定的教学和考核时间。 |
| **学期制** | semester | semester system | 部分学校用 semester 制度（两个学期）。 |
| **课程** | course/class | module/programme | 在英式英语中，“course”可指整个学位课程（如历史课程），而“module”指课程中的单门课。“class”是更非正式的说法。 |
| **讲座** | talk | lecture | “talk”泛指任何讲解或演讲，而“lecture”指课堂上由讲师或教授进行的正式学术授课。 |
| **小班课** | class/tutorial | tutorial/seminar | tutorial 一般是一对一或小班指导，seminar 偏向小组讨论。 |
| **实验课** | lab | laboratory session | 理工科常设实验课，正式文件写 laboratory session。 |
| **老师** | prof/teacher | lecturer/professor | professor 在英国仅用于正教授，普通老师称 lecturer。 |
| **导师** | teacher | supervisor | supervisor 常指研究/论文指导老师。 |
| **助教** | TA | teaching assistant | 助教通常是研究生或博士生，负责辅助教学、批改作业或解答学生疑问。 |
| **作业** | homework | assignment/coursework | 大学中通常使用“assignment”或“coursework”指论文、报告等任务，取代学校中的“homework”。 |
| **小论文** | paper | essay | essay 是本科阶段常见的短篇书面作业，通常 1000–3000 词。 |
| **大论文** | thesis | dissertation/thesis | 本科/硕士叫 dissertation，博士叫 thesis。 |
| **小组作业** | group work | group assignment | 学生合作完成的项目或展示，通常是课程考核的一部分。 |
| **演讲展示** | presentation | oral presentation | 课堂中常见的考核方式，需要幻灯片和口头讲解。 |
| **抄袭** | copying | plagiarism | 学术不端行为，学校会用 Turnitin 检测。 |
| **拼凑** | patchwork | collusion | collusion 指未授权合作，属于学术不端。 |
| **补考** | resit | resit examination | 未通过课程需参加 resit。 |
| **重修** | retake | retake module | 需重新选修整个课程模块。 |
| **成绩** | marks | grades | marks 指具体分数，grades 指等级结果（如通过、优秀等）。 |
| **成绩单** | mark sheet | transcript | transcript 是正式学业证明。 |
| **学位等级** | grade | degree classification | 英国本科分为 First, 2:1, 2:2, Third, Fail。 |
| **学术支持中心** | study help | academic skills centre | 学校提供写作、演讲、学习技巧辅导。 |
| **考试** | test | exam/assessment | exam 指正式考试，assessment 包括各种考核方式。 |
| **开卷考试** | open-book test | open-book exam | 允许查阅资料的考试。 |
| **论文提交** | turn it in | Turnitin submission | Turnitin 是最常用的论文查重与提交平台。 |
| **选修课** | optional class | elective module | 非必修课程，可按兴趣选择。 |
| **必修课** | must-take | core module | programme 中规定必须修的课程。 |
| **退课** | drop | withdraw from module | 正式流程称 withdraw，需要导师同意。 |
| **出勤率** | attendance | attendance record | 部分课程有强制出勤并计入平时分。 |
| **成绩复议** | remark | marking review/appeal | 对成绩有异议可申请复核或申诉。 |
| **学术警告** | warning | academic warning | 成绩长期不达标会收到 academic warning。 |
| **学分** | credits | academic credits | 通过完成课程模块获得的单位，英国本科每年通常需修读 120 学分。而硕士一般需要 180 个学分。 |
| **注册** | enrol | enrolment / registration | 在学年或学期开始时正式注册课程或学位项目的流程；英式拼写是 enrol、enrolment，美式才写 enroll、enrollment。 |

<h2 id="sec-4">学术写作与研究</h2>

| 中文 | 口语（同学之间） | 正式（邮件、作业、文件） | 说明 |
| --- | --- | --- | --- |
| **引用** | ref | citation/reference | citation 指正文中的引用，reference 指文末的完整文献信息。 |
| **参考文献** | refs | bibliography/reference list | bibliography 更学术化，reference list 更常用。 |
| **提纲** | plan | outline | 论文写作前的结构规划，常需提交给导师确认。 |

| **研究假设** | guess | hypothesis | 研究前提出的假设命题，需要通过数据检验。 |

📌 **使用建议**

- **查词按场景，不按字母。**这张表是按「你在干什么」分的五类，遇到具体场景直接跳到对应小节；要精确找某个词，用浏览器的 Ctrl+F（手机上是「在页面中查找」）。
